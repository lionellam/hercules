Review card: making the next step obvious

After Parse, the review card should read as a step you need to finish, not as one more section of the screen. These mockups show three levels of change, from light to strong. All are on the Log screen only; the same card when editing from History or the Today list is unchanged. Dashed blue outlines mark what's new.

Recommendations, roughly in order of impact:

  1. Say it isn't saved yet. A small amber "Not saved yet" tag and a clear heading, "Check the details, then save", in place of the small grey label.
  2. Make the card stand out. A stronger border and a shadow, so it sits above the screen instead of in line with it.
  3. A bigger Save. A full-width "Save expense" button, with Discard as a quieter button beneath it.
  4. Show the fields can be changed. A small "›" beside each value, as in Settings.
  5. Quiet the rest of the screen. Fade the Today list while you review, so the card is the only thing asking for attention.
  6. One place to look. While reviewing, fold the typed box into a single line ("You typed … Edit"), so the dimmed Parse button no longer competes.
  7. Bring it into view. Scroll the card into view when it appears, with a brief fade-in (motion isn't shown here).

Round 2 — Bottom sheet, with the existing wording (owner's direction, 14 November 2026)

Option C, reworked: after Parse, the review card appears at the bottom of the screen over a darkened Log screen, like the existing edit sheet (no handle, no animation). It keeps today's wording ("Review before saving", the typed text in quotes, "Discard") and adds no new text. Changes from today: the "›" on each line, and two full-width buttons, Save expense and Discard. Tapping outside the sheet does the same as Discard: the sheet closes and the typed text stays in the box, so it can be edited and parsed again. As today, if any detail was changed, Discard (or tapping outside) first asks "Discard your edits?", with no explanation text. Save expense is only for this review sheet; the edit sheet keeps Save.
