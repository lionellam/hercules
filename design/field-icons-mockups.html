Field icons on the review and edit sheets

A pencil beside each value shows it can be changed, on both the review sheet (after Parse) and the edit sheet (opening a saved expense). The date gets a calendar icon instead, as it opens a date picker. Both icons are drawn by the app, so they look the same on iPhone, Android and computers. Dashed blue outlines mark what's new.

The iPhone date problem: the date box is set to align right, but Safari on iPhone ignores that for date boxes and lays out the date its own way, so it sits left of the other values. The fix is a Safari-specific rule that aligns the date to the right. Today's calendar icon is also the browser's own: computers show one, but Safari on iPhone shows none. Drawing our own icon fixes both.
