CSV Button Contrast

The CSV button on Summary. Its label is already easy to read (16:1). What's hard to see is the button itself: its pale grey fill barely stands out from the page, at 1.1:1 in light mode and 1.19:1 in dark. Accessibility guidance asks for 3:1 for the edge of a control. Each option below is shown in light and dark, with the rest of the screen unchanged.

A · Current

For comparison. In light mode the button is close to invisible; it reads as the word "CSV" with an icon.

RecommendedB · Outline

No fill, with a mid-grey outline 1.5 pixels wide. The edge passes 3:1 in both themes, and the button stays quieter than the total and lighter than the dark Parse and Save buttons, so it still reads as a secondary action.

C · Darker fill

The same filled style one shade darker. It's more noticeable than today, especially in dark mode, but still well short of 3:1 against the page.

D · Solid

Styled like the app's main buttons (Parse, Save expense). The strongest contrast, but it pulls the eye away from the total and makes downloading look like the main thing to do on Summary.
