Confirmation sheets

Mockups for an in-app confirmation sheet, in four uses. The sheet slides up over whatever is open, with the main action on top and a way back underneath, like the edit sheets. On a tablet or computer it would appear as a centred dialog, as the edit sheets do. These use the app's own styles; nothing in the app has changed.

Blue dashed outlines mark the new confirmation sheet. Purple marks the "Undo" alternative in section 1.

1. Replacing the phone's own prompts

Delete expense and Retire category, which today use the phone's prompt. The red button names the action, so it's clear what will happen. Tapping outside the sheet counts as Cancel.

2. Discarding unsaved changes

Shown only when something in the sheet has actually changed and you tap outside it or press Cancel. If nothing changed, the sheet closes straight away as it does today.

Covers: Edit expense, Edit category, Add category, and the review card on the Log screen after parsing, when you've changed any of the parsed details before pressing Discard.

3. Possible duplicate

Shown when saving a new expense from the Log screen if it looks like one you've already logged. It shows the earlier entry so you can compare.

Proposed rule: an expense that isn't deleted, with the same amount and the same date, in any category. Only checked when logging a new expense, not when editing. Checked on the phone against the month's expenses already loaded, so no server change is needed.

4. Unusual values

Shown when saving a new or edited expense whose date or amount looks like a likely parsing mistake. It names what looks unusual, and the second button takes you back to fix it.

Proposed rules (only one sheet is shown; if more than one applies, they're listed together):
  • Future date: any date after today. Future-dated expenses already count towards that month's total and pace.
  • Old date: more than 60 days before today.
  • Large amount: over $500 and more than five times your typical (median) expense in that category over the last three months. With fewer than five past expenses in the category, over $1,000. So monthly rent at its usual amount never triggers it.

Not included

  • Routine actions (normal saves, Restore, adding a category, changing a budget) don't ask, so the prompts keep their meaning.
  • Sign out doesn't ask: signing back in is quick and nothing is lost.
  • Sections 3 and 4 warn but never block: "Save anyway" always works.
