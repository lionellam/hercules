Intelligent Merchant Selection

An experimental feature. When switched on, parsing matches a shortened or differently written merchant name to one you've already used this month, so "ntuc" or "fairprice" comes back as "NTUC FairPrice". Phone size, light appearance unless marked. Dashed blue outlines mark what's new. As agreed, the review sheet itself doesn't change: only the name in the Merchant line does.

1 · The switch, on Settings → Experimental features

The first real entry on the page, replacing "Nothing to try right now". Off until switched on, on each device.

2 · The review sheet after Parse

The same entry, "ntuc 45.20", parsed in a month where "NTUC FairPrice" has already been logged. The sheet is exactly as today; only the Merchant value differs.

How it behaves

  • Which merchants: those on your expenses dated in the current month. Names differing only in capitals or spaces count as one, using the spelling you've used most. At most the 50 you've used most often.
  • Nothing to match yet (early in the month, or no merchants logged): parsing works exactly as with the switch off.
  • Only on the Log screen's Parse. Editing an expense from History or the Today list is unchanged.
  • On each device: switching it on on your phone doesn't switch it on on your computer.
  • Privacy: while on, this month's merchant names are sent to the parsing model along with each entry.
