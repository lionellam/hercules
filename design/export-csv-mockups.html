Expense report download (CSV)

A download on Summary saves the expenses for the month you're looking at as a CSV file, which opens in Excel, Numbers or Google Sheets. On this month it covers the 1st to today; on last month, the whole month. These mockups use the app's own styles and example figures. Dashed blue outlines mark the new control.

Where the button goes

Three placements on Summary. In each, the download follows the month selected at the top.

The downloaded file

One row per expense, oldest first, with plain column names. Deleted expenses aren't included. Below is how the file would look when opened in a spreadsheet.

⤓ hercules-expenses-2026-11.csv

To decide

  • Placement: A, B or C. I'd suggest A: it sits with the month it downloads, is easy to find without taking space from the figures, and works the same on a phone and a computer.
  • Columns: as shown, or fewer (for example without "What you typed" and "Edited").
  • File name: hercules-expenses-2026-11.csv for both months, or add the end date for this month (hercules-expenses-2026-11-01-to-2026-11-09.csv) so repeated downloads don't look identical.
  • On a phone: iPhone shows its usual "Save to Files / share" options; Android saves to Downloads. The file is made by the app's server rather than in the browser, which works reliably in the home-screen app too.
