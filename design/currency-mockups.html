Default currency

A Currency row in Settings sets the currency used whenever what you type doesn't name one. The server applies it, so Claude can no longer turn a plain "$12" into USD. The review card gets a currency picker with the same 20 currencies, and budget labels and lists follow your default. Dashed blue rings mark what's new.
